# решения мейнтейнера

решения по новым патчам десктопа (0125–0322, lib_ui), принятые при разборе очереди. номера — текущие номера патчей десктопа ([desktop-numbers.md](desktop-numbers.md)); `A0068` — файл `patches/android/`. планирование — [PATCHLIST.md](PATCHLIST.md), оценки — [portability.md](portability.md).

два уровня:

- **мейнтейнер** — спрошено и отвечено, решение обязательно.
- **по умолчанию** — решил лид при разборе, пока мейнтейнер не ответил; мейнтейнер может переиграть, тогда правится и план, и оценка.

## подсистемы целиком (мейнтейнер)

| тема | решение |
|---|---|
| деньги / кошелёк (0285–0290, 0296, 0297, 0307, 0309–0313, 0317) | портируем всё, включая приватные ключи 0310/0311: дифф wallet-engine переносится на ревизию wallet-engine в Android, Rust пересобирается. новая страница настроек `MODE_MONEY`. 0285 — портировать и проверить на тестовом кошельке. карта 0307/0317 — 2D и 3D-шейдер. 0297 (ресайз окна money) отдельной работы не имеет — окна нет |
| скриптинг (0302, 0303, 0320) | портируем всё, включая веб-платформу 0320. движок quickjs-ng через NDK, как на десктопе |
| html-пузыри `.tgw` (0314–0316) | портируем; рендер litehtml через NDK, как на десктопе |
| подарки | массовые действия (0184–0186, 0190, 0192, 0193 + раннер 0213), локальный пароль (0187 + 0217; свой пароль + биометрия, сброс через облачный пароль, как на десктопе), студия подарков (0197, 0204, 0234), fake-апгрейд с ролл-анимацией (0198, 0201) |
| центр уведомлений (0205 + 0206, 0212, 0232, 0239, 0240, 0246–0248 там, где зависят от него) | портируем, нативный JNI-хук в tgnet для flood wait (первый хунк форка в `jni/`). вход — строка с бейджем в настройках tele (по желанию ещё и локальный чат tele) |
| mtproto-инспектор и консоль (0088, 0195, 0218, 0298) | портируем и инспектор, и консоль; TL-схема в комплекте |
| приватность — база первой | список игнора (0016/0073), per-chat ghost и ghost-schedule (остаток 0032) — в ранний батч; затем 0166, 0227, 0228, 0229 поверх |

## правки к уже перенесённым патчам

по очереди десктопа изменились патчи, уже перенесённые на Android; в плане они оформлены отдельными строками пачки 11:

1. 0017 (влит бывший 0043): время `· HH:mm:ss` у сервисных сообщений — опция секунд на Android их не покрывает.
2. 0077: пресеты перезаписи ссылок — TikTok только `tnktok.com` (миграция сохранённых `vxtiktok.com`), `samekosabax.com` в пресет X и в regex трекинга.
3. 0095: точный отложенный — учёт попыток, `FLOOD_WAIT`/`SLOWMODE_WAIT`, лестница повторов, максимум 5 попыток, уведомление.
4. 0006: апдейтер — докачка (`Range`, `.part`), лестница повторов 1/5/15/60 мин при сетевых ошибках.
5. 0253: копирование голых цифр peer id из строки профиля (android 0025 копирует отформатированный текст строки).
