# решения мейнтейнера

решения по новым патчам десктопа (0125–0322, lib_ui), принятые при разборе очереди. номера — текущие номера патчей десктопа ([desktop-numbers.md](desktop-numbers.md)); `A0068` — файл `patches/android/`. планирование — [PATCHLIST.md](PATCHLIST.md), оценки — [portability.md](portability.md).

два уровня:

- **мейнтейнер** — спрошено и отвечено, решение обязательно.
- **по умолчанию** — решил лид при разборе, пока мейнтейнер не ответил; мейнтейнер может переиграть, тогда правится и план, и оценка.

| скриптинг (0302, 0303, 0320) | портируем всё, включая веб-платформу 0320. движок quickjs-ng через NDK, как на десктопе |
| html-пузыри `.tgw` (0314–0316) | портируем; рендер litehtml через NDK, как на десктопе |
| подарки | массовые действия (0184–0186, 0190, 0192, 0193 + раннер 0213), локальный пароль (0187 + 0217; свой пароль + биометрия, сброс через облачный пароль, как на десктопе), студия подарков (0197, 0204, 0234), fake-апгрейд с ролл-анимацией (0198, 0201) |

## решения по базе приватности (пачка 11)

| тема | решение |
|---|---|
| режим игнора (0016) | режим (`hide`/`fade`) задаётся на каждого peer в пикере, а не одним глобальным тумблером, как в десктопе. список хранится в `tele_kv` с account в ключе |
| игнор и слова (0016, 0166) | игнор скрывает или гасит сообщения и превью; слова всегда скрывают полностью. свои, сервисные и sponsored-сообщения не трогаем |
| превью в списке чатов | если последнее сообщение скрыто, превью не показывается. подстановка более раннего сообщения, как в десктопе, не перенесена: истории чата нет в синхронном доступе на UI-треде |
| ghost по чатам (0032) | per-chat работают только typing, read и contents-read. онлайн-статус остаётся глобальным, как в десктопе: per-peer онлайн невозможен |
| ghost-schedule (0032/0064) | задержка 12 секунд, как в десктопе. в android нет мастер-тумблера ghost, поэтому признаком ghost-режима считаем включённый `ghost_schedule` вместе с глобальными ghost-переключателями |
| ожидающие сообщения (0227) | локальная копия ghost-scheduled сообщения лежит в чате, а не в списке отложенных; при доставке сервером строка обновляется, второго ряда не появляется |
| last seen (0282) | правило last seen меняется на allow-users, статус читается, исходное правило восстанавливается и переживает перезапуск приложения. пункт — в меню чата, тумблер выключен по умолчанию |
| streamer mode (0160) | приоритет над 0113 (never block screenshots): пока включён streamer mode, `FLAG_SECURE` всегда стоит. заголовок окна и трей — desktop-only |
| поиск | новые privacy-строки получили id 1110–1120: диапазон 1100–1119 из [docs/batches/batch-11.md](batches/batch-11.md) уже занят фичами предыдущих пачек (calcmula, shot) |
| ghost mode | добавлен общий мастер-тумблер «Ghost mode» (выключен), как в десктопе: переключатели online/typing/read/viewed/scheduled работают только пока он включён. per-chat «always ghost» работает и без мастера. состояние видно в счётчиках «always ghost in (N)» / «never ghost in (N)» |
| игнор-лист | только люди, каналы и группы игнорировать нельзя — как в десктопе. кнопка «Ignore messages» в профиле появляется, пока включён тумблер «show the ignore button in the profile» (по умолчанию включён — кнопку просил мейнтейнер) |
| слова | по умолчанию сообщения гаснут, полное скрытие — тумблер «hide the messages completely» (в десктопе наоборот: fade по умолчанию, полное скрытие отдельной опцией) |
| read при ghost | пункт «Read» в меню сообщения помечает сообщение прочитанным локально, без отправки read receipt. появляется только когда включён ghost read |
| пикер исключений (0016, 0032) | пикер игнора и ghost-исключений — стоковый экран пересылки (`DialogsActivity`, `DIALOGS_TYPE_FORWARD` + `selectAlertString`): список чатов с галочками, счётчик получателей и нижняя панель, как при пересылке нескольким людям. в режиме игнора выбираются только люди (как в десктопе), группы и каналы нельзя отметить. свой список чатов с поиском удалён |
| живое превью ghost (0244) | карточка «you / what they see» в разделе ghost, над мастер-тумблером: заголовки — системные сообщения (цвета `key_chat_serviceBackground`/`key_chat_serviceText`), строки — плашки профиля из заголовка диалога (настоящая аватарка, имя, статус) с бейджем stealth на аватарке, «On my way…» — поле ввода, «See you tomorrow?» — пузыри (наш с одной галочкой = не прочитано), «Their story» — кружок истории с буквенной аватаркой и текстом справа, «12 views» — иконка stealth. клик по строке переключает соответствующий тумблер, пока ghost включён, иначе карточка приглушена. строка сторис показывает «watch stories invisibly» и не переключается — отдельного «не отмечать сторис просмотренными» в android нет |
| иконка stealth | взята стоковая `R.drawable.msg_stories_stealth2` — та, что telegram использует для premium-пункта «Hide My View» в историях (`PeerStoriesView`). свой вектор с перечёркнутым глазом удалён |
| краш в профиле | `TeleHooks.onPrivacyRulesChanged` отправлял `NotificationCenter.messagesDidLoad` без аргументов — `ChatActivity` читал `args[10]` и падал с AIOOBE. теперь чаты перебиндовывают ячейки по счётчику ревизии (`TeleHooks.uiRevision`), а список чатов обновляется через `dialogsNeedReload` |
| peek last seen | если правила приватности ещё не в кэше, tele грузит их с сервера и ждёт до 10 секунд, вместо сообщения «the privacy rules are not loaded yet» |
| регистр строк форка | строки форка (экраны, пункты, диалоги, тосты, поиск) с заглавной буквы — как в android-телеграме; в десктопе всё в нижнем регистре. «tele» всегда строчными, включая «tele server URL» и «New in tele». технические строки (sql, регулярки, ключи, коды ошибок) и статусы вида «online»/«recently» не менялись |
| телефон в streamer mode | в режиме стримера номер не показывается нигде, где он мог бы служить именем: в заголовке чата (для не-контакта телеграм подставляет номер вместо имени), в `UserObject.getUserName` (fallback на номер → «Unknown»), в своём профиле (строка «Mobile»). в десктопе тот же приём — `Tele::StreamerPhone()` отдаёт пустую строку |
| переход из поиска | результат поиска открывает страницу tele и проматывает её к нужному тумблеру с подсветкой. используется стоковый механизм: `SearchResult.rowName` + `AndroidUtilities.scrollToFragmentRow`, который ищет в фрагменте поле `listView` и поле с номером строки — форк отдаёт туда поле `teleSearchRow` |
| link rewrite | цель при «Pick a random target» выбирается случайно на каждую перезапись (раньше — по хешу ссылки, и одна и та же ссылка всегда превращалась в один и тот же домен). уведомление — телеграмный баултин с «домен_до -> домен_после», а не системный тоаст |

## правки к уже перенесённым патчам

по очереди десктопа изменились патчи, уже перенесённые на Android; в плане они оформлены отдельными строками пачки 11:

1. 0017 (влит бывший 0043): время `· HH:mm:ss` у сервисных сообщений — опция секунд на Android их не покрывает.
2. 0077: пресеты перезаписи ссылок — TikTok только `tnktok.com` (миграция сохранённых `vxtiktok.com`), `samekosabax.com` в пресет X и в regex трекинга.
3. 0095: точный отложенный — учёт попыток, `FLOOD_WAIT`/`SLOWMODE_WAIT`, лестница повторов, максимум 5 попыток, уведомление.
4. 0006: апдейтер — докачка (`Range`, `.part`), лестница повторов 1/5/15/60 мин при сетевых ошибках.
5. 0253: копирование голых цифр peer id из строки профиля (android 0025 копирует отформатированный текст строки).
